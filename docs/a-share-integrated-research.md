# A股综合预测：使用、来源与验证

本轮在原助手上追加综合研究，Qlib尚未安装或接入。蓝色价格回归、原5/10/20日AI价位、首页已保存策略、筹码/新闻、持仓与原回测继续保留。新情景统一标记“研究估计，尚未校准”，不承诺准确率或收益提升。

## 使用

1. 打开 `/assistant` → 个股行情，选择股票。报价下方的“综合研究与价位”是统一生成入口，紧接着是K线；详细研究、来源与历史报告保留在图下。
2. 首次展开“资料与重新生成”，点击“更新研究资料”。免费源优先；取财务、估值、公告列表及最多6份正文、相关新闻，不调用研究模型；第三方搜索可能消耗已有搜索额度。正文下载/提取失败分别保留缺口。
3. 点击“生成综合研究与价位”，后台统一运行最多6类角色并生成5/20/60交易日情景与条件策略，不再从助手同时启动旧版3–5角色流程。手动没有每日次数上限；相同资料和模型的完整成功结果复用缓存，部分结果可显式重试。“重新生成（按用量计费）”显式跳过缓存，产生新的模型用量。查看、切换期限/图层、读取报告、刷新行情均不调用模型。
4. 统一入口显示实际阶段、阶段完成百分比、已用时和预计剩余范围。阶段包括资料准备、六类研究、价位校验、保存；阶段失败或因资料不足跳过会明确标记。百分比根据已处理阶段计算，运行中最高95%，结束后显示100%及完整/部分结果状态，不把单个模型的内部推理伪装成线性进度。用时从实际开始时间计算；剩余时间使用本次已完成角色耗时中位数及0.5–2倍范围估计，超出已有估算时改为未知。首次尚无耗时样本、资料准备和升级前运行的旧任务不虚构剩余时间。
5. K线旁保留当前期限的偏弱、基准、偏强数值区间。没有提供或未通过来源校验的区间显示“未提供”及可得的拒收原因；不填默认价格。资料变化时旧区间标为历史参考，生成期间旧结果标为上次已保存情景。
6. K线勾选“综合研究情景与策略”，按偏弱、基准、偏强分色展示同次研究已发布且不超过所选期限的5/20/60日节点与区间。节点的连线取区间算术中点，阴影连接各节点区间，均只是显示示意，不代表逐日价格路径、条件会依次发生或经过校准的中位预测。指向节点可查看期限、图表口径区间、成立条件及来源；缺失节点明确列出，不补值，也不将较早期限结果延长到缺失的后续期限。只有一个已发布时点时连线仍为直线。策略价位继续使用原粉色虚线。原蓝色数值基线和首页报告线继续独立控制。原始/前复权历史的来源、末日、价格、复权基准及获取批次必须精确匹配；旧研究、过期计划和不同资料的研究保留数值及详情，但不叠加到新图，并解释未叠加原因。新的有效报告与行情匹配后恢复图层。
7. 原“AI价位与情景”5/10/20日结果及“研究观点与共享证据”在图下折叠区只读保存，不再暴露另一套收费生成按钮；旧API继续兼容，不删除旧报告。展开资料、角色、可比事件和实绩，可核对来源、实际发送ID、裁剪项、缺失及拒收原因。AI角色是同模型的研究分工，不是外部独立专家。

模型阶段全部处理结束不等于预测价位生成成功。某些角色调用失败且未产生任何有效价位时，统一入口显示“价位生成失败”，列出失败角色，并在K线旁说明没有可绘制区间；不会显示“部分结果有效 · 100%”暗示已有价位。角色均处理完但依据不足时显示“未发布预测价位”，与调用失败区分。已有有效区间及成功观点仍保留，图层价格版本校验不放宽。

调用错误仅保存允许列出的可读分类，不保存子进程参数、密钥或服务商原始响应。已识别的Arrearage提示模型账户欠费或余额不可用，额度不足、限流、认证及超时分别提示；只保存通用异常类型的旧记录无法事后还原具体原因。不存在自动付费重试；账户恢复后需要显式重新生成，原资料仍可复用。详情参见[百炼错误码](https://help.aliyun.com/zh/model-studio/error-code)。

请求提交期间采用同步锁，已接受的后台任务保持锁定直到权威读取确认结束；迟到的旧查询和暂时读取失败不会重新启用生成按钮，也不会把旧报告误标成本次已完成。此锁减少误操作，不替代服务器任务锁；跨页面新开任务仍由服务器按股票拒绝并行执行。

资料准备和研究运行分开。单股任务完成后，同业以最多20家公司一批后台补录；“补充下一批同业资料”从20、40等起点继续，最多500。同业任务不占用行情队列的工作线程，但共享供应商的限速/冷却，完成时间取决于上游。服务停止后准备任务可恢复；运行中的模型线程不跨进程恢复，已有已完成报告保留。

## 本次真正使用的数据

| 维度 | 来源与输入 | 作用和限制 |
| --- | --- | --- |
| 技术/市场 | 既有同源raw/qfq日线、沪深300、MA120/250及完整周线、ATR、收益和成交额 | 进入价格基线和专家；临时当天K线不进入完整日线统计 |
| 行业 | 东方财富分类及已抓取成分；父子分类只有成员集严格可证明包含时选最细行业 | 用于当前行业研究与抓取同业；不把今日成分当过去成分；行业历史/相对强弱不足须保持未知 |
| 业绩/财务 | 东方财富主指标、利润表、现金流量表、资产负债表；有相应权限时优先Tushare | 归母/扣非利润、收入、ROE、毛利率、负债、现金流、EPS等按源字段保留。最新修订版本仅用于当前研究，不能回填历史已知事实 |
| 估值 | 免费stock_value_em，或有权限的daily_basic | 当前PE/PB与自身历史PE分位；供应商重建历史不是点时数据库，无完整输入不拼历史PE |
| 公告 | 巨潮原公告，授权anns_d可提供列表 | 保留ID、报告期、公开时间、正文片段、链接和哈希；仅官方PDF白名单，8MiB、80页、解析15秒上限 |
| 新闻/政策 | 复用已配置搜索/Tavily，按代码和核实公司名检索 | 实体、链接、发布时间严格核对；当天只有日期、未来新闻和未知发布时间不作为事实输入；严格早于截止日的日期新闻可作当前背景，保留日精度与实际观察时间，不用于历史事件归因，搜索摘要不冒充全文或完整新闻库 |
| 资金/筹码 | 当前流动性只采用可核对完整日线成交额 | 原筹码入口保留；既有筹码记录未带完整价格版本时不会强行送入新研究。逐笔资金、机构持仓和一致预期明确缺失 |

每项报表字段显示有无取得。累计、单季、母公司及调整版本的供应商类型随事实送入模型，混合类型分别列值，不直接聚合。类型含义参考[Tushare利润表官方说明](https://tushare.pro/document/2?doc_id=33)。现金含量只在同一报表内同时有经营现金流与归母利润且分母非零时计算，避免跨期间或报表类型拼接。金额统一人民币元，比例统一小数；未知不是零。Tushare预设不代表权限，关闭免费回退后空付费响应也不会转用免费源。外部研究观点未取得可核对作者/机构、日期、原文时不补造；系统AI角色不是外部真实专家。

## 事件与策略如何影响预测

六类角色为市场/行业、业绩/估值、事件/历史案例、价格/流动性、风险复核、综合经理；最后两类收到前面角色的有界结论。每个角色有完整JSON输入预算，实际发送与未发送的资料ID单独留档。默认48000字节，可在现有模型部署YAML的`model_info.assistant_research_input_bytes`调整，范围3000–192000；已声明`max_input_tokens`时进一步保守裁剪。沿用现有模型及推理/输出/超时配置，没有新增密钥要求。

事件强度优先直接核对原文。目前自动数值抽取覆盖明确引用的净利润同比变化范围；同比不等于“超预期”。订单分母、商品敞口、预期差等不足时只作定性材料，不套固定涨跌百分比，也不暗中逐事件收费抽取。本次`extraction_calls=0`。更正同报告期预告归同家族，取截止前最新已核对版本；撤回公告不保留正面强度。近20个完整交易日的已核对事件可作当前催化，超过的只作背景。

历史匹配先过滤时间、类型、方向、历史行业版本、重复家族，再匹配市场状态、事前/当前阶段20日涨幅、强度分档及可用估值。事件已经过去若干交易日时，案例收益也从相同已过去的阶段起算，避免把已实现的公告反应再预测一遍。分别报告1/5/20/60日个股收益、市场/行业超额、不利变动与首次可交易开盘起算表现。多个事件或市场冲击仍可能混杂，不能解释成因果效应或可交易利润。

相同期限至少10个不重叠事件、5家公司，且严格匹配维度齐备，才允许历史分布提供数值参考。免费历史行业无法核实时不会凑足样本；今天新增的行业留档只支持未来事件。没有案例参考时，综合价位仍受已发送的同期限价格基线范围约束，新闻/财务影响条件和情景选择；本轮没有训练新闻到涨跌幅的数值融合模型。

候选策略包括趋势回踩、区间回归、事件跟踪和观察，分别受长期/周线、市场相对状态、当前已核对事件和身份/ST/市场范围约束，不按专家投票决定。数值校验要求止损<入场<第一目标，入场、止损及盈利目标在引用范围内，所有价位统一到0.01元后复核；潜在收益风险比及示例成本后空间均需达标，不满足则观察，不抬高目标。成本仅按100股示例、原佣金最低费/过户费设置和0.2%税费/滑点储备估计，不是实际账户费率或历史成交回测。未满足条件的虚线只是观察参考，不能绕过原账户/T+1/风险约束。

## 评价与接口

按实际生成时间、股票、锚点、来源及5/20/60日分别保存。终点尚未成熟、生成时终点已过去、生成时间晚于锚点下一交易日收盘、来源/锚点不一致或交易日缺失的记录不计入前瞻成绩。盘中发行无法核实当天低点是否已发生，路径不利变动留空。成熟后列绝对价格误差、方向、实测情景覆盖、不利变动和独立窗口数量。仅在同一批实际记录交集上比较“不变价格/价格模型/综合情景”。没有真实财务单项或事件单项实验时显示未验证。

综合策略收益尚未验证。新流程尚未取得全部停牌/涨跌停可成交路径、历史股票范围、T+1持有和有效日期成本资料，因此不提供组合年化、Sharpe或盈利胜率。Qlib及新组合执行/回测在后续实施，本轮接口可以提供有来源的数据基础。

- `GET /api/v1/a-share/market/stocks/{code}/integrated-research`：只读资料、研究、进度和验证。
- `POST .../research-data?peer_offset=0`：准备来源，不调用AI。
- `POST .../integrated-research?force=false`：显式后台研究，最多6角色。
- `GET .../research-validation`：只读成熟预测实绩。

沿用现有认证；成功响应也可能表示等待历史或资料不足。`demo`不抓真实研究资料，来源切换或旧任务迟到不能覆盖当前配置。新增记录放入原追加式日志和任务表，不新增数据库，不修改旧报告。

```sh
.venv/bin/python scripts/integrated-research-smoke.py --code 000807
# 以下两项有显式副作用，generate会产生模型用量：
.venv/bin/python scripts/integrated-research-smoke.py --code 000807 --prepare
.venv/bin/python scripts/integrated-research-smoke.py --code 000807 --generate
```

脚本有界等待且只提交一次生成，不自动循环重试，输出计数/状态不输出密钥。需要现有登录时可通过`DSA_SMOKE_COOKIE`传入当前本地会话。回退方式：关闭综合图层或不点生成，继续查看已保存研究；历史记录不用删除。撤销本轮代码必须按交付文件清单逐项操作，不能重置含其他未提交功能的工作区。

新闻实体过滤要求标题直接识别公司名称或独立六位代码；仅正文/推荐侧栏出现该股票不计为公司新闻。此规则更保守，会漏掉标题未提公司的真实报道，来源缺失如实显示。v4资料契约使旧版本报告保持历史可查并标记过期，不能自动覆盖到当前K线。

资料准备不调用研究LLM，但复用的第三方搜索可能消耗已有Tavily额度；是否超出免费额度以该服务账户为准。未发布某期限策略时页面明确提示，不默认补齐买卖价位。当前资料与历史研究各自显示独立价格锚点。
