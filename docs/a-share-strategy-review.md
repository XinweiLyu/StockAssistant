# 策略选择与验证边界

2026-10-16新增[综合研究](a-share-integrated-research.md)：多维资料及六类AI角色追加到原有基线之外，按5/20/60交易日给出受引用范围和适用条件约束的研究情景。趋势回踩、区间回归、事件跟踪需分别满足适用状态；当前不满足则观察。下面的固定规则仍独立运行，新研究未改变它们的权重。

同类历史事件增加强度、阶段涨幅、市场状态和历史行业核对；最新修订财务和今天的行业成员不当作过去已知信息。10事件/5公司的数值门槛不保证因果或预测有效性。新增前瞻归档只比较已经生成且成熟的预测，共同样本上的误差对照不能称成本后策略收益；未实际生成的单财务/单事件实验保持未验证。当前没有综合策略组合收益结论，Qlib尚未接入。

本次没有把GitHub星数、报告篇幅、多角色共识或作者宣传的高收益当成策略有效性证明。DSA提供应用能力，CN提供结构化研究角色；两者都不能替代数据质量、样本外测试和交易成本评估。

| 方向 | 本次决定 | 需要额外验证的关键条件 |
|---|---|---|
| 日线趋势/动量 | 两套固定版本基线 | A股可能反转、震荡假突破、涨跌停买不到、回撤与行情依赖；参数不是历史优化结果 |
| 行业趋势 | 资料足够时运行 | 行业分类必须一致，不能把当前成员当历史成员；没有足够行业指数则停用 |
| 价值、质量、股息因子 | 暂不加入评分 | 报表公布时间、修订、点时数据、行业可比性；低价不能直接解释为低估 |
| 新闻驱动、情绪 | 证据与风险过滤 | 摘要缺上下文、发布时间不等于发现时间、主体歧义、谣言与重复转载 |
| 均值回归 | 后续可比较基线 | 极端下跌可能为基本面变化；T+1与跌停可能阻止及时退出 |
| 涨停打板、盘口、套利、高频 | 不适合本次数据频率 | 五分钟快照不提供逐笔路径、盘口队列和可成交证据 |
| Qlib/机器学习/RL | 预留扩展方向 | 时间切分、特征泄漏、训练成本、过拟合、多次试验偏差、非平稳市场 |
| 网上的“高收益策略” | 不直接采信 | 代码/数据版本、幸存者偏差、未来函数、费用滑点、容量、止损路径及样本外记录 |

第一版的默认仓位上限、ATR参数、收益窗口和70分门槛是可解释研究起点，未证明最优。既没有依据这些结果优化参数，也没有声称已建立可交易的盈利优势。

后续验收顺序：固定版本与数据记录 → 连续前瞻观察 → 按真实T+1、费用、涨跌停、停牌做独立组合回测 → 样本外比较及手动成交记录。候选记录从“保存后首个交易日收盘”开始，避免用保存之前的历史涨幅冒充预测结果。

先比较样本量、5/10/20日价格表现及缺失率，再增加最大回撤、波动、换手、成本后收益、容量与基准。缺少组合资金路径时，不提供策略年化收益、Sharpe或胜率宣传。基准如只使用价格指数，不能直接称严格总回报超额收益。

策略文件有确定的输出及边界测试：未来/未完成日线、重复日期、OHLC错误、复权缺失、交易日历空缺、并列排名、样本不足、风险/手数/费用、报价过期/未知、涨跌停/追高、已核实风险、T+1未知/超卖、午休与收盘、固定观察端点。

## 2026-10-14 多周期统计基线

新增`price-ridge-outlook-v1`与原`trend_v1`/`sector_trend_v1`并存。MA120/250和完整周线为价格状态信息；固定正则化岭回归比较5/20/60交易日价格分布，按时间滚动训练、隔离未来标签、仅用训练样本标准化，区间残差来自更早的非重叠样本外预测。价格不变为误差对照。至少80个训练标签、8个成熟非重叠残差后才发布对应区间。发布区间的实测覆盖需要另有足够成熟样本，不能拿残差拟合覆盖率冒充外样本准确率。

本次加入模型训练和时间外价格检验能力，没有测得相对原策略的成本后收益优势，也没有实现Qlib迁移或完整账户组合回测。展示条件式计划需要长周期/周线、市场/相对强度、误差对照和盈亏比同时满足；目标不人为抬高。账户股数、T+1、涨跌停、现金与仓位检查继续由原模块执行，数值基线不能使被阻止的交易恢复可执行。

事件库统计已保存、已核实、首次可用时间已知且有成熟同日基准价格的非重叠反应窗口。它是描述性比较，未形成经验证的新闻预测增量；普通检索和今天获得的消息不能用来假定系统过去已经知道结果。样本不足时展示证据缺口而不估计胜率。后续升级仍须固定实验版本、比较价格基线与附加新闻/财务模型、记录全部参数试验和前瞻表现，再决定是否启用新的决策权重。
