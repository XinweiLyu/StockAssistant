# A股价值投资研究

价值研究位于交易助手的个股K线下方，持有期为6、12、24、36个自然月。原有短期交易、事件案例、技术指标、历史报告与行业/概念浏览继续保留。Qlib训练不是本模块的依赖。

## 怎么使用

1. 在K线上方“研究内容”选择价值投资或两者，点击生成。需要补齐资料时，页面会先准备财报、股本和同行，再自动继续一次已明确请求的价值模型复核；单独“更新研究资料”仍只调用数据源。
2. 从同一入口查看准备与研究阶段进度，无需为同一次生成再次点击。价值部分最多一次模型请求，分别检查经营质量、估值、反方与资本分配；同一模型的多个视角不代表独立专家投票。两者都选时，原短期研究最多6次，价值研究最多1次。
3. 图下查看依据、缺口、错误定价假说及反证。展开“假设编辑与免费计算”，核对数据和预测参数；也可以完全不使用AI，手动填写假设。
4. 保存草案不会调用模型；“确认假设并计算”保存版本并由程序计算。确认是用户的研究记录，不能证明事实或未来假设正确。
5. 主方法保守/基准/有利三情景、关键资料及风险检查合格后，才能比较安全边际。长期图层默认关闭，按需勾选；草案、争议、过期、股本或复权基准不匹配时不绘当前价值线，卡片保留历史结果。

只有显式点击“生成价值研究”才会在当前页面内等待资料准备并继续一次模型请求。切换股票或离开页面会取消尚未发起的续接，返回不会恢复收费；查看、轮询、改期限、保存参数和单独更新资料不触发模型。准备超过15分钟、数据任务失败、资料版本过期或证券不匹配时停止且显示原因。模型请求失败或中断不自动重试；只有手动重新生成才开启新的模型任务。仅有快照、尚无模型研究或估值草案时，明确显示“资料已准备，尚未生成AI研究”，不标成已完成但资料不足。

## 错误定价与安全边际

低PE、股价跌了、同行更贵都不能独立证明低估。报告把市场担忧（可能只是推断）、支持证据、最强反证、验证节点和失效条件一起保留。质量、价格与依据可靠性分开展示，不合成盈利概率。

以已确认主方法的保守普通股每股值V、当前有效不复权价P为参考：

- 安全边际=(V−P)/V。
- 到保守价值的潜在涨幅=(V−P)/P。
- 用户要求安全边际m后，条件参考价上限=V×(1−m)。m是投资者的要求，不是模型发现的事实。

例如V=80、P=60，安全边际25%，潜在涨幅33.3%；要求30%边际时参考上限56。估值偏乐观时折价并不能保护本金，必须同时看压力情景、债务、资本需求、稀释和反证。重大风险、证券身份未核实、股本不明、当前价格无效、关键核查未完成时暂停条件价。

## 来源与财务口径

免费优先复用东方财富三大报表与财务指标、巨潮公告原文和已有新闻搜索。有Tushare权限时沿用原配置；不自动购买或升级档位，不需要新建模型或搜索密钥。

每个价值事实保留证券、单位、期间、合并/母公司、归属主体、公布/修订/观察/可用时间、原字段、来源及哈希。最新修订财报不能当作历史当时可知资料。未知不填0、负利润不删除，冲突不静默择优。

TTM只在同口径资料齐全时使用“本期累计+上年年报−上年同季累计”。资产时点不相加，比例/每股数不直接累计差分。合并CFO与归母利润主体不同，不标成严格现金转化率。

当前总股本另行核对，不使用流通股或注册资本替代，也不从市场价与近似市值反推。免费个股信息源失效时，会列明缺口；旧年报股数不能自动作为当前股数。当前资本快照与财报期分别保存，避免股本更新把整份财报“变成缺失”。

“补充缺失财务事实”要求原文网址、公布日期、期间、单位、引用与理由，标记人工核对，产生新快照。不能覆盖供应商原事实、证券身份或已核实重大风险，不能用于历史回测。自己的录入错误可指定原人工事实ID更正，旧journal与快照仍保留；供应商冲突不会因此消失。

## 跨行业与同行

使用版本化的东方财富行业目录映射经济模型：普通经营、强周期、成长、早期项目、银行、寿险、财险、券商、资管、融资租赁、公用事业、资产/控股。歧义保持待识别；人工修正需主营来源和理由。

银行不套普通企业FCFF，保险与租赁等有各自资本/风险清单；亏损不作正PE排名；周期利润需要完整周期及规模/产能变化检查；创新药没有成功率/成本依据不编造管线rNPV。所有产业有研究入口，不代表每家公司都具备数值估值所需资料。ETF、基金和REIT不混作普通企业。

同一概念不等于同行。各公司独立识别行业及经济模型，主营可比依据与财报期间对齐后才能正式比较。PE/PB还须逐指标对齐估值日、定义和来源，逐指标展示排除理由，不能拿相同季报期掩盖不同日期的估值。候选可逐家填写主营原文、可比理由并人工确认；指标本身不合格仍排除。每指标至少5家合格样本才发布分位，排除自身，显示N、中位数、Q1/Q3及`count(peer<=target)/N`。正PE与正净资产PB分别筛选，不机械平均PE。自身分位固定最近5年窗口，披露请求/实际起止、样本数及可得交易日历覆盖率；最新PE非正时不会回退到旧正值。

周期正常化视图按逐年盈利或现金流/营收的均值乘当前TTM营收，保留亏损年及来源，覆盖不足5个连续完整年度不称为完整周期；营业利润不是EBIT。这个视图只按规模调整，不能自动识别并购、产能或主营断点。周期企业须填写有来源的完整周期与结构变化判断，并把调整反映到三组经营输入，否则暂停条件价，不能把历史均值当成保证。

## 确定性估值器

主方法与交叉方法分别保留，不任意加权平均。有效基准值差超过主方法值30%会进入争议复核；这是产品审查阈值，不是置信度。

| 方法 | 计算与约束 |
| --- | --- |
| FCFF | 营收/利润率→税后经营利润+折旧−capex−营运资本增量；WACC折现后加独立非经营资产、减债务/优先索取/少数权益。缺桥接项不补0。 |
| FCFE | 普通股可分配现金流按权益成本折现；已计利息/融资后不再减债一次。非经营资产仅可“流入已计入”或“独立净值”二选一。 |
| RIM | 普通股账面权益+未来剩余收益现值，RI=盈利−权益成本×期初权益。显式分红、OCI、资本约束与衰减。首版非零OCI/不完整资本桥接暂停计算。 |
| DDM | 五年普通股股利及稳定期股利折现，要求盈利、债务、监管资本支持分红，回购不当现金股息相加。 |
| NAV/SOTP | 不重叠资产/分部调整价值−负债/索取权−税费/处置成本，再除普通股数。未知重大分部不得声明完整。 |

显式预测期5年，企业价值仍包括之后的经济寿命。终值第6年现金流按独立稳定期经营/投资假设计算，不直接放大尚处过渡期的第5年。DCF/DDM折现率至少高于终值增长1个百分点；不合法参数直接提示，不自动夹紧。

首版DCF/RIM采用已核实固定普通股资本，未来融资增发、回购、重组需要完整资金/股数勾稽，否则暂停该数值路径。“无额外收益摊薄10%”仅为明确的压力假设。压力测试还覆盖利润/投资、折现率、银行ROE或资产折价等；压力值不是概率。

## 事件与长期情景

事件只能修改有单位、原值、新值、作用年限、衰减与来源的经营假设。同一事件族、驱动、情景、方法和年份不能重复叠加；允许同一事件分别影响保守/基准/有利情景。已进入基准的变化不能再计一次；原值不匹配或缺经营桥接时保留定性判断。展示变更前后对照，不把历史事件股价涨幅直接加到内在价值。

已有可比历史事件研究可作为价格是否提前反映的证据。样本0仍显示0，不把当前同行成员冒充过去成员，不放宽时间门槛制造命中。没有可靠一致预期，不能把同比增长叫“超预期”。

今天的价值V0与持有期Vh共用同一现金流排程；默认估值日起逐年周年末支付，明确分红日同时影响两端。日期按ACT/365.25折现。6/12/24/36月是自然月；终点已经分出的股息不再留在终点价值里。

价格兑现因子k=Ph/Vh。长期不纠偏维持初始P0/V0，而非维持旧股价；不会自动使36个月k=1。总回报包含期间实际分红，未填税费只展示毛收益。

DDM可重估剩余股利并计算持有期情景。FCF缺自由现金流—实际分红—留存现金—非经营资产的完整勾稽时，先展示当下价值与复核节点，不补造终点价格；NAV缺未来处置/债务计划同理。长期价值水平带也不等同于每日股价预测。

## API与版本

均在原认证边界 `/api/v1/a-share/market/stocks/{code}` 下：

| 接口 | 行为 |
| --- | --- |
| GET `/value-research` | 读取缓存、过期原因与进度；无外部抓取/模型。 |
| POST `/value-data` | `{peer_offset,refresh}`，手动准备资料，每批最多20个同行候选。 |
| POST `/value-research` | `{snapshot_id,force}`，可选一次付费草案研究。 |
| PUT `/value-assumptions` | `{snapshot_id,expected_revision,assumptions,confirmed}`，乐观版本保存。 |
| POST `/value-evaluate` | `{snapshot_id,assumptions_revision}`，确定性计算。 |
| POST `/value-supplement` | `{snapshot_id,facts,attested:true}`，最多50条人工资料。 |

版本为`value-research-v3`。数据、行业/同行、股本、来源、风险与假设变化后旧记录保留但不充当当前结果；过期提交409，结构/数值错误422。资料缺失不要求模型先完成，缺K线也能先做价值资料研究。

队列按证券/快照/模型/假设版本原子合并运行中请求，force也不能绕过。模型请求前以数据库事务检查当前任务归属并唯一登记付费尝试，崩溃后结果未知则中断，不自动重试收费。同模型至少3次已完成实测耗时后，按历史耗时范围显示预计剩余时间；不足时显示未知；百分比是阶段比例，非模型内部进度。

价值研究复用原模型、密钥和显式推理/输出设置。未单独设置时，本流程默认最多8192输出token、300秒超时；已配置更高上限与超时则按原配置，不设重试。原短期调用默认值不变。AI拟议假设的所有嵌套引用也必须来自实际送达证据，包含事件、反证与主营修正。

旧AI观点随资料、假设或模型变化退为历史，不覆盖新的人工假说；同页保留历史估值报告供对照。

分红送转通过[东方财富免费详情](https://akshare.akfamily.xyz/data/stock/stock_issue.html)或[Tushare dividend](https://tushare.pro/document/2?doc_id=103)获取。保留税前每股现金、预案/实施、除息日和可得的派息日。免费数值单位仅在明确“每10股派”原文时换算；除息不等于到账，不以当前股数反推过去现金总额。未知字段不自动变成未来分红。

## 验证边界

本模块验证计算、资料契约、版本与实际通路，不据此宣称具备已验证超额收益。历史时点数据不足时，不进行含未来信息的估值回测。参考[CFA现金流估值](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/free-cash-flow-valuation)、[剩余收益估值](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/residual-income-valuation)及[Damodaran正常化盈利](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/normearn.htm)。

本专题暂无对应英文文档，未修改README、产品预览或推广内容。

实际验证与部署记录见[交付记录](a-share-value-validation.md)。

个股资料的总股本接口失败时，复用同一批已下载的东方财富估值日`TOTAL_SHARES`（股），或Tushare `total_share`（万股换算），不另加付费请求。保留真实估值日与观察时间；不使用流通股、注册资本、旧年报或市值除以价格推算股本，不将周五数据改写成周末核对日。准备覆盖清单单列股本来源与失败/回退状态；缺失时继续给出具体缺口，暂停不满足约束的估值和条件价。

价值研究v2按资料类别分配输入：优先当前估值日报价和倍数、当前财报与股本、最近分配、重要报告的资本/经营原文片段及完整年度核心指标，再填充其余历史。原文片段带实际偏移与原长，不直接截断序列化JSON。输出保存已发送和未发送证据ID；资料未送达与来源本身缺失分开表述。每10股送转并派现的描述以最初的10股为分红基数，不误把送转股数当基数。规则升级后旧快照/研究保留历史，需按v2重新准备与研究。

无估值报告时，价位卡区分“尚未生成”“研究中”“本次未形成估值”，不将尚未执行的研究标成依据不足；条件参考价不满足时仍暂停发布。已生成报告的方法缺口保留真实提示。

v3将完整年报、最近正式季报/半年报及资本公告列为价值资料队列优先项，不以业绩说明会或摘要替代；PDF上限仍为8MiB，600页、80万字符及45秒隔离解析。审计意见、受限现金、现金流附注保留原文偏移，模型输入仍不超过48KB；财报共同单位/主体及来源用显式默认项和别名压缩，腾出公告与同行的输入位置。新增字段均保留原始字段名，空值不转0；同一折旧汇总的兼容字段不重复相加。同行仍是候选，不自动发布未经主营确认的行业分位。

DDM可在`fixed_capital:false`下使用`capital_bridge`，其他方法的固定资本限制保持。路径为待核对的预测假设：当前总股数减库存股得到初始外部普通股；逐年分别处理新发、回购、注销、库存股再发行，再用有权分红股数折算股利。回购现金只进入企业现金约束，不额外加作投资者现金收益。每年股息不超过当年归母盈利，期末可用现金须覆盖最低经营现金；稳定期假设股本不变且股利不超过盈利或经营现金减投资。现金与股数缺字段、非法注销/再发行、资金不足等均停止该情景。

年度及稳定期现金约束使用十进制金额比较，避免0.30−0.10−0.10因二进制误差被错判不足0.10；现金预算扣除经营现金流之外的融资费用与少数股东分配，不把这些未知现状填0。

`opening_available_cash`表示本情景纳入的期初可用资金，不代表货币资金事实；明确取0可以表示不依赖存量现金，不能宣称未知现金不存在。股本现金路径可在假设编辑中逐项修改，报告列示逐年分红股数和现金；6–36月持有期沿用同一调整后现金流及分母。AI仅提交未确认草案，当前资本、来源、审计/债务等风险和用户确认仍决定能否发布条件安全价，不以数学可计算冒充事实已核实。

若当前AI研究为partial且没有估值报告，额外返回只读`reference`，不改变原AI判断，不调用模型或写入历史。仅对风险资格合格的operating企业，要求期间不旧于400天、同期间且有来源的TTM归母利润/CFO/capex/利息，以及少数权益、当前总股本和库存股依据；缺失不补0。零库存股报表之后有回购披露时暂停自动参考。正库存股成本要求同股巨潮公告中的累计回购数量与金额，金额须与账面库存股成本接近（1%内），也只作为最近披露基准假设，不证明报价日实际库存股。

参考组使用显式软件敏感性参数：较保守/中间/较有利分别为折现率12%/10%/8%、经营增长0%/3%/6%、稳定增长0%/2.5%/4%、CFO系数75%/90%/100%、目标分红率50%/65%/80%。未来逐年股利取盈利目标分配与扣再投资、融资现金风险准备、少数权益风险准备及经营储备后的现金上限较低者；并非公司指引或已经验证的预测。只依赖未来经营回款，未来债务净融资及新增资本行动均为0的情景假设，不是确认已续贷或不会回购。初始经营储备为压力后CFO的10%，融资现金风险准备为TTM利息的1.2倍，少数现金风险准备为当前少数权益全额逐年预留；这些是试算控制参数，不能冒充真实支出。
