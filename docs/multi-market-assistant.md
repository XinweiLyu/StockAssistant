# 港股、美股交易助手

交易助手在同一页面提供 A股 / 港股 / 美股切换，K线直接放在报价下方，沿用现有指标、六角色综合研究、未来情景、事件研究、价值研究和手动假设工作流。A股的旧API、数据和规则继续保留。

## 使用与数据

- 在市场按钮切换后搜索代码、英文名称或现有目录的中文别名。港股支持 `00700`、`hk00700`、`0700.HK`；美股类别股如 `BRK.B` 会映射至供应商的 `BRK-B`。
- 目录来自现有索引，身份、交易币种及行业需行情源核实。目录不是交易所全量实时证券名册；索引以外可用代码直接查询。行业只含已核实的覆盖公司，暂不提供独立行业指数涨跌或虚构概念热力图。
- 行情首选 Yahoo/yfinance。美股个股遇到 yfinance 请求失败时可经 Yahoo Chart 获取常规时段报价和日线，使用供应商的报价时间。原始与供应商复权日线一次成对获取，记录分红/拆股及共同版本。复权含分红调整，不能当作成交价。当前未把 Stooq 单侧日线或 AKShare 异步复权结果拼成这一对；来源失败时显示原缓存和真实获取时间。
- 个股档案暂缺报价币种时，从同一证券的已有报价读取币种，用于匹配 K 线和数值预测图层。证券身份及财报币种仍以相应的独立核实资料为准。
- 个股 K 线在后台补齐数据源可提供的日线。顶部期间调整视窗，滑块仍可移到已取得的最早交易日。「全部历史」可显示完整缓存。短期间包含最新完整日线时继续显示匹配的预测，回看旧日期后可点「回到最新」查看预测。板块和指数查询继续使用原时间限制。
- 可手动刷新报价；可见且已选定的港/美股每五分钟检查一次。免费数据可能延迟，刷新不调用AI。盘中临时K线与已完成日线分开，只有证券、日期和复权版本一致时叠加。
- 交易日按香港/纽约时区、交易所节假日、美国夏令时及半日市处理。港股数值研究在[港交所收市竞价最晚结束时点](https://www.hkex.com.hk/en/Services/Trading-hours-and-Severe-Weather-Arrangements/Trading-Hours/Securities-Market?sc_lang=en)后认证日线（全日16:10、半日12:10）；未知个股竞价资格时保守多等待最多10分钟，旧常规时段标签保持原语义。2023-09-01、2023-09-08港股临时休市按港交所公告显式纠正；不会把缺失价格自动当成休市。

## 综合预测与历史事件

先在研究工具中准备资料，再生成综合研究。读取、轮询、行情刷新和确定性估值不发起模型请求。一次综合研究最多六角色请求，沿用现有进度、引用核验、缺口、历史版本及手动重新生成入口；一次价值研究最多一次请求。实际费用由原配置的模型供应商收取，无新增强制收费数据源。

价格基线采用完整历史、波动与趋势，给出5/20/60交易日区间。市场参考分别是标普500 `^GSPC`、恒指 `^HSI`，不冒充行业或风格参照。综合预测融合已获取的财报、新闻、原文事件和专家反方判断；资料不足仍可能只有价格基线和定性讨论。

事件只在原文、发布时间、相对市场状态、事前涨幅、强度、历史行业归属和结果窗口合格后进入可比统计。同市场样本优先且显式隔离；标题/搜索摘要不变成完整公告，业绩同比变化不等于超预期。当前接入后的历史行业归属逐步归档，不回填假历史，因此新市场初期合格事件样本可能为0。

美股官方财报使用SEC标准US-GAAP/IFRS标签及申报目录。可选配置：

```dotenv
SEC_USER_AGENT=
```

请填写真实的应用名称及联系标识，遵循[SEC自动访问政策](https://www.sec.gov/about/developer-resources)。不填写仍可用供应商财报，页面会显示官方源缺口。SEC自定义未映射标签不猜测语义，重复上下文冲突保留。港交所原文通过现有搜索发现并核对官方PDF与公司身份；这不是完整的港交所历史公告API。现有Tavily等搜索配置直接复用。

## 价值与上市单位

财报按原币种保存，例如腾讯可能为人民币财报、港币报价；年度、52/53周财年、独立季度、累计期间与半年报分别归一化。供应商修订财报仅可用于当前观察，不能当作历史当时已知资料。分红记录是待核实候选，除息日不等于支付日，不能凭候选自动认定可持续股利。

原生企业价值与每个上市单位的价格比较分开。需要在“股权与汇率核实”中提供公开原文、摘录、股权/ADR比例、生效日、资本行动覆盖日及当前股数；人工核实记录留痕。报价币种与财报币种不同时，只使用不晚于锚点且7日内的有来源直接或倒数汇率；不默认CNY=CNH，不猜ADR比例。缺少这些绑定时，企业研究仍可阅读，但安全边际、条件安全价、持有期收益及正式价位叠加暂停，并逐项提示。

沿用FCFF/FCFE/RIM/DDM/NAV、同行可比性确认、经营质量/资本回报、错误定价与反证、安全边际、经营失效监控、6/12/24/36个月持有情景、事件驱动和冻结预测复核。未来假设仍需引用和审阅。对齐资料不代表准确预测；估值不完整时显示具体缺口。港美股尚未配置券商费用、交易手数与账户约束，因此保留毛收益风险比，暂停净收益风险比和可执行交易条件，不能套用A股100股/税费。

## 接口、隔离和回滚

统一入口 `/api/v1/market-workspace/{cn|hk|us}`，使用应用原有认证。支持股票、日线、报价/刷新、行业/成员、研究资料/综合研究、价值资料/研究/假设/计算/补录、自选和上市单位绑定。`cn`委托旧服务。港美股使用 `us:AAPL` / `hk:00700` 等身份；缓存、队列、自选和研究记录按市场隔离。手动调用计入原模型用量账本；读取不计费。

改动不迁移或删除原数据库。回滚时停止当前进程，恢复部署前文件及前端构建，再用原方式启动；不要覆盖 `.env`、设置或数据库。新市场缓存和记录可留存，旧服务不读取新命名空间。浏览器截图和一次性验收数据库不进入Git。

中文操作文档新增此专题；英文市场支持文档同步能力边界，无需扩展README或产品预览。
