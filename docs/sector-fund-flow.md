# 板块资金流与动态趋势

在交易助手切换至“行业与概念”，选择A股行业或概念板块，成分股上方显示资金面板。可选择盘中采样或近5/20/60交易日，勾选主力、超大单、大单、中单、小单，以及板块涨跌和主力区间累计。鼠标移动或下方时间滑块可查看每个点。成分股保留原跳转，并显示资金净额/净占比；个股K线下方可展开已核实行业的同一面板。

板块总览可切换涨跌幅、主力净流入、主力净占比排序；资金排序仅使用来源累计快照，未取得值放在末尾并显示资料不足。港美股和非东方财富分类目前没有等价资金源，明确显示未支持，不用成交额替代。

## 口径与数据来源

- 免费公开数据取自东方财富，与AKShare `stock_sector_fund_flow_rank`、`stock_sector_fund_flow_hist`使用同一字段口径。直接绑定`em:industry:BKxxxx` / `em:concept:BKxxxx`；不按名称合并申万、同花顺或同名概念。
- 原始金额为人民币元，图表以亿元显示；百分比统一为小数后再格式化。0是有效值，未获取为null。
- 主力是来源按成交单大小的分类，包含超大单和大单。各线独立绘制，不能叠加重复计数，也不等于已证实的机构持仓。多个概念成员可能重叠，不能将板块资金相加称为市场总流入。
- 盘中是页面开启后每5分钟查询的**当日累计数采样**，不是每5分钟新增资金。同一个时间桶替换，绝不求和。仅连续交易时段存采样，日切、午休和超过8分钟采样缺口断线。未提供交易日期/时间的源快照明确标为未知，采样时间不能证明报价属于今天。
- 日历史独立保存源交易日期及系统观察时间，仅统计交易日历确认的已收盘日。近N日指N个应有交易日，缺失不压缩、不补零；累计在缺口后保持未知。当前未完成日不加入日统计。
- 近5/20日主力净额、连续净流入天数、近3日减前3日净额均来自连续完整日窗口。后者是净额变化，不是价格预测或涨幅。

公开端点：排行/成员 `https://push2.eastmoney.com/api/qt/clist/get`（同官方延迟域名及`push2his.eastmoney.com`可回退）；日历史 `https://push2his.eastmoney.com/api/qt/stock/fflow/daykline/get`。排行按板块类型共享一次分页请求，成员及历史只查询所选板块；分页必须完整且无重复代码才能发布。总请求预算22秒，隔离子进程仍受现有40秒上限保护；不修改全局代理。公开服务可能限流、拒绝连接或调整字段，具体可用性以面板状态为准。

## 刷新、缓存和费用

可见页面每5分钟检查，后台获取中的任务短轮询直到完成，隐藏或离开页面停止轮询；服务关闭时不会持续采样。日历史按已完成交易日复用；手动“刷新资金数据”可提交刷新，重复点击复用进行中的任务。失败沿用现有后台最多3次/间隔15分钟重试策略，按钮不会制造并行任务或绕过上游冷却。来源失败保留上次缓存及原获取时间；各部分状态分别显示。

没有新增数据订阅、模型配置或自动AI费用。生成综合研究时，只读取同股已核实行业、研究截止前已观察到、价格锚点以前的已收盘缓存；至少5个完整日才注入市场类证据。20日不足则该字段为空。资料保留真实观察时间及`latest_reconstructed`，不能倒推为历史当时已知。原六专家流程接收这条来源证据，不改变已冻结旧报告，也不据此自动生成额外买卖点或弯曲预测线。

## 接口与验证

现有认证保护下新增：

- `GET /api/v1/a-share/market/sectors/fund-flow-rankings?kind=industry|concept`
- `GET /api/v1/a-share/market/sectors/{sector_id}/fund-flow?period=0|5|20|60`
- `POST /api/v1/a-share/market/sectors/{sector_id}/fund-flow/refresh?period=...`

复用现有队列、profile及设置/任务版本发布保护。SQLite只新增日资金版本和盘中采样表，不删除已有记录。

离线验证：`python -m pytest -q tests/test_a_share_sector_flow* -m 'not network'`。真实源探测需显式设置`RUN_SECTOR_FLOW_NETWORK=1`并运行`tests/test_a_share_sector_flow_network.py`，不会读取账户配置或调用AI。2026-11-17本地联调：同代码日历史返回120条，实际适配器测试通过；本地真实页面“其他数字媒体”近20日覆盖20/20、曲线存在且浏览器无错误。早期实时排行/成分股资金的主/延迟线路连接失败；随后同日验证了历史网关上的相同资金排行路径，已加入备用线路，完整496板块排行及日历史的真实适配器测试通过。仍不把快照生成时间当作源交易日期，分钟历史未验证可用。资金面板会分别报告来源状态，多日曲线不依赖排行成功。

当前数据由历史接口独立提供。收盘前观察到的当日日资金即使过了15:10仍保留临时性质，必须重新取得收盘后的观测，才能参与日统计及研究。所选板块日历史任务优先于批量预热；一个来源失败不会阻塞其余来源更新。

## 多板块同图比较今天的资金变化

在“交易助手 → 行业与概念”顶部查看“今日资金流入变化”，无需逐个打开板块详情。每条颜色不同的线代表一个板块：默认关注6个、最多8个，可搜索并勾选；行业和概念分别记忆选择，首次默认选择也会保存，返回页面时保持原关注对象。下方原有热图、排行和成分股导航保留。点击对比表中的板块可进入原详情。

默认比较主力累计净流入，支持超大/大/中/小单，金额和净占比独立切换。横轴统一为9:30–15:00的5分钟采样窗口，午休、缺失窗口及真实观测相隔超过8分钟时断线，单点画点。移动光标或拖动时间滑块，对比表显示同一个窗口内各板块数值；该窗口没有数据的板块显示“—”，不会沿用早先值。“最近采样值”是另一独立列，并列出实际观测时刻。

这是**今天系统采集到的资金快照**，来源交易日期仍未核实。没有采集到的数据不会补画成开盘以来的曲线，也不使用昨天/每日资金替代今日分时。免费实时排行线路连接失败时，面板会显示来源问题，尚无真实点的曲线保持空白；有数据后每5分钟自动更新。官方分钟接口探测目前没有取得可验证序列，未接入未经验证的替代字段。

新增`GET /api/v1/a-share/market/sectors/fund-flow-comparison?kind=industry&ids=em:industry:BK0478,em:industry:BK0438`；最多8个相同分类且目录中存在的不同板块。仅排队一次共享排行任务、读取已有今日采样，无逐板块历史请求、模型调用或额外付费。离开板块页或隐藏页面暂停读取；后台存储仍按原队列及采样机制执行，不承诺关闭服务后的连续覆盖。
