# A股事件影响路径：研究结论与完整升级设计

日期：2026-10-17。性质：设计与现状核对；本文不表示产品已完成这些能力。本次未修改运行代码、未调用付费模型、未购买数据。

审阅：已完成独立实施可行性审阅，未发现必须补问用户的重大需求缺口。数据实际覆盖与数值效果仍待实施核验；审阅通过不等于预测有效性通过。

## 1. 结论与选择

不再用“发生后20个交易日”统一决定事件是否有效。应同时维护：

1. 原始资料的检索与归档范围；
2. 事件的业务生命周期及下一次核验节点；
3. 市场已经反应到什么程度；
4. 从今天起5/20/60/120/250个交易日的研究或预测期限。

四个时间概念分开。20日可以保留为近期信息标签及短期观察窗口，不能承担事件到期规则。长期经营影响也不等于未来还会持续产生正超额收益。

选择“事件持续跟踪＋条件匹配历史路径＋增量影响统计＋综合风险策略”的路线。单纯延长时间窗不能处理兑现、重复报道、撤回、预期差、市场已反应等问题；让大模型自由编写每日价位也没有足够数值依据。

初期沿用现有服务和数据源，不引入第二套代理框架；先做可解释的检索、统计估计与滚动验证。Qlib仍放在后续实验管理和模型扩展阶段，不是取得事件样本或推断因果的替代品。

## 2. 研究依据与适用限度

- DellaVigna、Pollet的原始研究把即时反应与第2至75个交易日的延迟反应分开衡量。这支持观察超过20日，不支持将该美股样本的效应直接套到今天的A股。[论文原文](https://eml.berkeley.edu/~sdellavi/wp/earnfr080204.pdf)
- Shu、Tan的A股研究发现，注意力、意见分歧与财报后的漂移有关。该证据提示纳入信息环境，不提供某只股票的确定涨幅或期限。[原始论文](https://www.tandfonline.com/doi/abs/10.1080/1540496X.2022.2079975)
- Kothari、Warner指出多年事件收益检验可能产生严重误判。其研究并非对本设计120/250日期限的直接检验；这里据此要求控制混杂与严守验证，不声称观察越久越准。[论文原文](https://leeds-faculty.colorado.edu/bhagat/KothariWarner1997.pdf)

下文所有初始时间范围是工程上的研究配置，须用A股样本验证，不是上述论文推荐的统一持有期限。

## 3. 当前代码核对到的缺口

代码位置均相对于现有项目 `outputs/a-share-assistant`：

- `src/services/a_share_integrated_service.py` 当前通过 `active_catalyst=age <= 20` 判定活跃催化，并仅选一个最近事件进行案例匹配；这不足以表达并存的中长期事件。
- `src/services/a_share_event_cases.py` 把已过去的交易日限制在0—20；现有收益观察为1/5/20/60日，尚无完整的条件路径与持续、衰减估计。
- 事件家族及撤回处理已有基础，但正文数值核对主要支持净利润同比表达，不能称为通用的订单、产能、政策、监管事件强度模型。
- 单次资料任务只对优先级靠前的6篇公告补取正文；公告列表多不等于正文、事件和可比样本已经齐全。
- 财报、估值和新闻已经参与研究，但当前图表没有已验证的事件增量价格路径。连接情景区间中点不能替代该模型。
- 紫金矿业本次保存结果中严格匹配样本为0，数值依据只有B5/B20/B60价格基线；不能用该结果证明事件量化已经工作。

## 4. 事件生命周期与不同观察期限

| 类型 | 初始研究节点（交易日） | 持续跟踪的实际依据 |
| --- | --- | --- |
| 突发消息、传闻、澄清 | 1/5/20，必要时60 | 原文确认、澄清、更正、后续经营影响；短期反应结束后仍可保留背景 |
| 业绩预告、快报、定期报告、指引变化 | 5/20/60/120 | 下一次修正、报告和盈利验证；同一报告期归为一个事件家族 |
| 订单、扩产、并购、重大项目 | 20/60/120/250 | 签约、审批、交付、投产、收入确认、终止；不能按公告金额直接当利润 |
| 产业政策、供需与商品周期 | 20/60/120/250 | 政策落地、需求、价格、库存、公司敞口、成本及对冲变化 |
| 监管、诉讼、违约及重大经营风险 | 1/5/20/60及持续复核 | 官方进展、解除或执行结果；未解除不能仅因时间久而消失 |

窗口不等于有效期，也不承诺每个窗口都输出价格。250日研究可能只给经营验证与估值条件；没有成熟样本和有效验证时不发布250日事件价格带。

生命周期使用证据支持的状态：已确认待兑现、兑现推进、结果确认、被后续版本替代、终止/撤回、状态待核实。消息热度和经营状态分别记录。经营已确认但市场是否消化属于统计估计，不伪装成可直接观察的事实。

一个老事件若缺少近期核验，标记“需更新状态”，不能自动一直生效。后续进展应更新同一事件家族，只把新增信息作为一次新的增量；重复转载不刷新事件年龄、不增加独立样本数。

## 5. 整条路径的输入、算法与输出

### A. 发生与确认

保存事件家族、版本、事件发生时间、首次公开时间、首次获取时间、生效时间、已知里程碑、原文、核对片段、来源及哈希。严格区分发生时间与投资者当时可获取时间。

公司事件以巨潮、交易所及公司披露原文为主；政策回到主管机关原文；新闻搜索用于发现线索。正文未取到、实体不明确、仅有转载摘要时，显示限制，不能自动形成数值催化。

历史按可得性先回溯5年，必要时再扩展并分年代验证；增量采用更新时间水位与家族复核，不重新扫描全历史。

### B. 是否超预期、是否改变经营

- 业绩：比较实际结果与公布前可获得的同口径预期；记录归母/扣非、单季/累计、现金流与一次性项目。机构一致预期没有接入时，该字段为未知。与上次指引或自建时序预期比较必须单列名称，不能冒充机构一致预期。同比增长不等于超预期。
- 订单：看新增性、可执行性、金额占当时营收比例、确认周期、利润率及收款风险；意向协议与确定合同分开。
- 产能与并购：看审批和交付进展、融资稀释、资本支出、爬坡、产量、成本及兑现期限。
- 政策/商品：先识别收入、成本、产量、库存、汇率、对冲等业务敞口，区分生产商和下游使用者。没有证据不能默认受益方向。
- 风险事件：明确法律/经营进展、最坏情况及影响范围，不以新闻情绪分数替代。

输出事实强度、预期差的依据和单位、经营传导假设、证据质量及未知项。大模型负责有引用的抽取与解释；价格影响幅度不由其自由指定。

### C. 是否已提前或事后反应

在事件首次公开前计算5/20/60/120日的个股表现、市场与行业相对表现、估值位置、波动和成交活跃程度；事件后截至当前再计算同口径的反应、回撤和新证据。

“提前上涨”只能作为已计价的代理线索，不能据此声称内幕泄露、确定兑现比例或必然利好出尽。重大事件前后同时有其他冲击时注明混杂。

事件已过去a天，研究的是从今天到a+h的剩余变化，不是把事件发生以来的全段历史涨幅再加一次。

### D. 匹配可比历史事件

先按事件机制、方向、可核对强度单位及公开时间过滤，再比较：当时行业与业务敞口、市场状态、规模/估值、预期差、事件前涨幅、波动/流动性、当时已经兑现的阶段。当前事件已经过去a天时，历史案例也按同一年龄和类似已发生反应匹配，且只能使用当时已知信息作匹配特征。

不直接平均“同为利好”的事件。采用可解释的分层检索；相似度、放宽了哪些条件、缺什么均对用户可见。关键传导机制不一致的样本不进入严格数值池；宽泛背景案例只作参考。

不同事件类型不能强制共用“利润同比”强度。历史行业未知不能用当前成分伪造；严格池与历史重建/探索池分开。

按事件家族去重，并处理同一公司重叠窗口、同一政策或同日市场冲击产生的相关样本。报告原始条数、独立家族数、公司数、年代覆盖、有效样本量和集中度。现有10个事件/5家公司只可作为探索性下限，不能单靠达到它就宣称可靠。

### E. 估计幅度、持续与衰减

保存可比案例事件前后完整的同口径日收益路径，而非只有第20天收盘一个数；同时保存市场/行业对照、最大有利与不利变化、何时达到峰值、何时回撤及后续里程碑。

条件化估计当前状态之后的收益分布、波动、回撤与持续范围。只有在同类样本的后续增量影响出现可辨识的减弱时，才报告衰减估计；不统一设置“每20天减少一半”。允许持续、反转、分阶段兑现及证据不足。

必须区分价格水平的一次重估与之后的新增收益：影响经营多年，不代表股价多年重复获得同一消息的额外涨幅。期限越长，新的事件与宏观混杂越多，解释和不确定性必须反映这一点。

### F. 真正改变未来区间，避免重复计算

保留价格基线作对照。先对严格案例输出“同类事件剩余路径”的研究分布，与基线分开；只有增量模型通过滚动验证后才发布融合价格带。

采用轻量的条件残差校正作为首选数值路线。对历史预测时点s与期限h，残差标签定义为：

`历史实际从s到s+h的对数收益 − 当时仅使用已知价格/市场信息生成的基线预测`

历史基线必须来自当时可得信息下的样本外预测；不能用今天训练好的模型回填训练期预测来估残差。用截至s已知的事件状态、预期差、先前反应和经营敞口解释这些残差，再把经验证的增量施加到今天的基线。这样不把新闻的历史全幅收益、行业涨幅和价格模型重复相加。

多条并存事件按家族及共同驱动分组，联合估计或用经验证的正则/收缩机制处理相关性，不能逐条百分比相加。同一政策影响的多家公司不能冒充很多独立政策实验。行业政策的总体影响与公司相对行业的特异影响分开，不能因为扣除了行业收益就宣称政策无效。

模型权重、收缩与融合强度由历史时间验证选择。样本不足、来源无法核验、验证不达标时，事件数值影响显示“未启用及原因”，保留定性风险与原价格基线；绝不把缺失写成影响为0。

区间要从联合路径或保持期限相关性的样本外残差中生成，不能把各模型的上下分位数直接相加。融合区间应重新检查覆盖与宽度，不能沿用基线覆盖标签。

### G. 图表、条件策略与后续更新

同一K线保留历史真实价格、事件标记、原基线、事件综合区间与策略虚线。点开未来节点能看到引用的事件、当前阶段、可比样本、剩余影响、缺失资料和失效条件。各来源分开标识，并保留旧报告查看能力。

未来基准路径如果存在统计支持的分阶段变化，可以有拐点；不能为了像行情而制造锯齿。逐日期间的分位数中线不是最可能发生的完整路径。若展示“先反应—回撤—验证”的完整示例轨迹，须来自成组历史路径或已验证的联合模型，明确它是条件情景，不能把不同样本逐日分位数拼成一条必然轨迹。

尚未公布的消息不预知。已知日期的财报/审批用条件分支表示超预期、符合预期、低于预期；未公布内容及无校准的分支概率留空。

策略从剩余空间、回撤风险、流动性、交易成本、持仓及失效条件形成观察/入场/减仓计划；价格区间不能直接等同于买卖指令。维持现有A股成交、T+1及涨跌停约束，不自动下单。

行情按现有5分钟检查机制更新；事件来源按可负担的增量频率检查。收到有效新披露或阶段变化后标记旧研究待更新。常规抓取与统计不调用模型；模型运行沿用手动触发和既有自动预算，前端显示进度、实际模型调用及资料缺口。

## 6. 数据与成本选择

优先复用当前行情/东方财富财务、巨潮公告、已有Tavily配置和本地追加式仓储。补齐的重点是正文、时间版本、事件家族、历史路径和覆盖管理，而不是立即增加模型角色或购买秒级行情。

一致预期、历史行业时点、经营敞口和长期商品/供需数据是单独的覆盖问题；来源未验证前不能宣称免费方案全部包含。不在本设计中假定新供应商价格、完整性或商业再分发许可。

每次任务显示覆盖：应有/已取/有正文/已核对/可进入严格样本/被排除及原因；每类事件都需真实案例验收。分批抓取、缓存正文、重复内容去重、失败可恢复，不在打开页面时扫描全市场或自动调用付费模型。

## 7. 接入现有项目的边界

- 在现有事件家族、ResearchBundle和仓储上追加版本字段，兼容旧报告；旧结果不能事后重写成新模型结果。
- 同步修改资料选择、事件年龄约束、案例收益路径、综合数值引用、模型提示与验证、API、前端标签、图表及评估；只改20这个常量不算完成。
- 原有首页、股票/板块筛选、手动行情刷新、指标、策略线、持仓、旧研究和自动预算保留。
- 数据、事件状态、模型和算法版本变更均参与哈希；过时研究保持可读但不得无提示绑定到新价格锚点。
- 120/250日新增区间通过验证后才开放，现有5/20/60日接口保持兼容；增加长期事件跟踪不依赖新增长期价格预测。

## 8. 完成标准与顺序

1. **生命周期与覆盖**：超过20日仍未兑现的真实事件能被保留；撤回、澄清、旧消息转载不会恢复失效催化；多事件并存可解释。正文覆盖和抽取缺口必须可见。
2. **预期与反应**：能区分同比/指引/一致预期；没有时点预期则明确未知。事件前后涨幅和当时对照能复核；同年龄剩余收益计算正确。
3. **案例与路径**：至少对财报类和一种非财报类完成真实端到端案例，并覆盖负向/失败情景。严格样本为0时不得生成伪事件影响。报告展示分层匹配及排除原因。
4. **幅度与衰减**：有可追溯的完整历史路径、阶段持续和剩余影响估计；样本不足不得硬给衰减天数。用确定性构造验证已发生涨幅没有重算。
5. **融合与策略**：比较价格基线、加入事件、加入生命周期、加入预期差等消融版本；未验证增量不替换默认基线。策略与图表使用同一版本数值。
6. **真实验证**：按时间滚动、按家族/共同冲击分组，标签窗口成熟且训练验证区间隔离；保留退市、失败事件和未兑现样本，披露存续与缺失偏差。检查区间覆盖、宽度与区间评分、方向及回撤；策略另计成本、滑点、停牌/涨跌停/T+1及可成交性。多种参数尝试保留最终未参与调参的测试期。
7. **运行验收**：页面展示完整进度和来源，旧功能回归，真实样本和离线失败路径均跑通，实际数据量/模型调用/验证区间留证据。通过测试代表实现正确，盈利或准确性提升只能由后续独立验证支持。

“事件影响路径已完成”须以上关键环节实际接通，不能用新增几个角色、扩大新闻时间窗、出现曲线拐点、写出设计或接口预留替代。
