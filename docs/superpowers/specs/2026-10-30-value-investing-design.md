# A股价值投资研究设计：错误定价、保守价值与安全边际

状态：待审阅，尚未实现。日期：2026-10-30。

## 目标与已经确定的要求

在现有交易助手的同一个股票详情中增加价值投资研究，适用于不同产业，持有期为6、12、24、36个自然月。保留现有报价、K线、行业概念、短期预测、事件案例、研究进度和账户风控。用户已经授权按格雷厄姆的原则实现；以下计算政策、数据门槛和界面细节由实施者提出，供核对。

价值研究回答：企业持续经营后能给股东留下什么、目前的价格隐含了什么、哪些证据支持市场可能错了、最强反证是什么、保守假设下有多少余地、什么情况会使判断失效。低市盈率、股价下跌、AI看多和同行更贵都不能单独证明错误定价。

成功标准是能对真实公司跑通“取数—可比性检查—显式假设—确定性计算—反方复核—报告—重检”，而非保证收益。所有产业能得到适配的研究清单、资料覆盖与同业候选；缺少关键资料的公司不强行得到数值估值。Qlib训练、自动交易、全市场自动付费研究不在本次范围。

## 核心区分

1. **现在的内在价值**：以研究日为估值时点，对企业整个经济寿命建模；显式预测期5年，续存价值必须单列。不能把持有3年等同于企业只经营3年。
2. **未来持有期情景**：6–36个月后剩余资产/现金流的价值、届时价格与价值的偏离、期间股息和费用。市场可能一直不纠偏。
3. **短期价格预测**：原有5/20/60交易日模型独立存在。价值估值不受其历史波动上下界裁剪，不能把长期价值画成确定的每日股价路径。
4. **企业质量、价格吸引力、依据可靠性**：分别呈现，不合成一个貌似盈利概率的分数。

## 数据与来源：免费优先，复用取数

沿用 `ResearchSources.financials()` 的东方财富免费财务指标、利润表、现金流量表、资产负债表；已配置且有权限时使用Tushare同类接口。每个原始响应同时进入原有事实适配器和新增价值事实适配器，不为同一份财报重复请求。公告与全文沿用巨潮资讯，新闻沿用已有搜索；新闻摘要不能覆盖财报数值。普通页面读取不启动网络抓取或模型调用。

新增规范化契约：`ValueFact` 包含证券、指标、值、单位、报告期、期间起止、合并/母公司口径、累计/单季/时点口径、归属主体、币种、原字段、来源、公告/修订/观察/可用时间、内容哈希、冲突状态。每项映射按接口定义，禁止把同名但不同含义的字段混用。当前供应商最新修订数据标记 `latest_reconstructed`，不当成历史当时可知数据。

| 数据组 | 本次提取与用途 | 缺失时处理 |
| --- | --- | --- |
| 经营与盈利 | 营收、营业利润、归母/扣非利润、税费、利息、折旧、研发、应收、存货 | 不从净利润代替经营现金流；研发费用不自动资本化 |
| 现金与资本 | CFO、资本支出、借款流入/偿还、已付利息、货币资金、受限资金、有息债务、短债、权益、少数股东权益 | 中国报表利息现金流分类先核对；CFO−资本支出不直接叫FCFE |
| 股东与分配 | 报告期末总股数、稀释股本、股息、已实施送转/增发、归母权益 | 流通股不代替总股本；最新股本变化不明时暂停每股估值 |
| 行业专有 | 银行资本与资产质量、保险类型/偿付能力、资源储量/成本、医药管线、房地产项目/债务等公告依据 | 显示行业清单和缺口，不补造专有经营数据 |
| 市价与比较 | 不复权报价、行情日、来源、PE/PB及历史、行业归属与成员快照 | 未核实或过时价格不计算“当前”折价；概念不作同行依据 |

经营流量使用合并报表，同一供应商、币种、期间与修订版本匹配后才能跨表连接；归母净利与合并CFO比较必须注明主体差异，不能称为严格现金转化率。年报最多展示最近10个完整年度及最近一期；完整TTM必须有本期累计、上年同季累计、上年年报，公式为本期累计+上年年报−上年同季。缺任一项不拼接。时点资产不能相加；比例/每股指标不通过累计差分求TTM。

报告版本不明、并表口径不明、跨源矛盾不能静默择优。保留冲突列表并阻止依赖该指标的估值方法。缺失与0严格区分，负利润保留。观察时点晚于研究截止日的资料不可进入历史重建。

Tushare `fina_indicator` 可提供FCFF/FCFE等字段，但仍是供应商口径，不能仅因字段存在就当成可持续预测。免费渠道没有等价字段时，使用具有明确利息分类、税盾、融资、资本支出与营运资本桥接的计算；桥接资料不全则提示缺口，允许用户带来源补充。不得自动升级付费档位。

手工补充通过独立 `value-supplement` 写入：必填原文URL/标题、公布日期、引用片段、值/原单位/期间/主体、补充理由、用户已核对标记。保存为 `user_attested` 的当前研究资料，创建新snapshot使旧假设失效，不能覆盖供应商原记录或用于历史回测。与已核实事实冲突时保留双方并进入复核，不自动解除门槛；无冲突且口径完整的人工核对资料可支持条件分析，但所有依赖它的结果醒目标明“依赖人工资料”，不可冒充供应商验证。证券身份、已核实重大风险与权限不能靠该入口改写。未来预测只能进入假设，不能伪装为历史补充事实。

## 行业适配与同行选择

先取已核实、唯一最细行业归属；多重且不能确定层级则保持歧义。配置版本化的行业到经济模型映射，结合主营业务证据；用户可修正但必须写理由与来源，留存原分类。仅有行业标签的公司属于候选同行，不能直接作为正式估值样本。

| 经济模型 | 首选研究/估值方法 | 重点风险 |
| --- | --- | --- |
| 稳定消费、服务、一般制造 | FCFE/FCFF现金流，正常化盈利与同业作交叉检查 | 护城河、再投资、应收/库存、资本效率、客户集中 |
| 资源、化工、强周期制造 | 完整周期正常化现金流；资产与成本位置交叉检查 | 高点利润陷阱、产能/储量变化、价格与成本联动 |
| 科技、成长、成熟药企 | 分阶段经营情景现金流 | 竞争、研发效率、稀释、现金消耗；亏损不算PE排名 |
| 创新药/早期亏损公司 | 管线/分部研究；有独立成功率和成本依据才允许NAV输入 | 无依据时不给数值rNPV，不套成熟公司倍数 |
| 银行 | 剩余收益RIM、股利DDM；PB与可持续ROE作交叉检查 | 不良、拨备、资本充足、净息差；不用通用企业FCF |
| 保险 | 区分寿险/财险；股利DDM或有依据的分部NAV | 偿付能力、准备金、投资风险；披露内含价值不等于股东清算价值 |
| 券商/资管/租赁 | 股利DDM或普通股NAV，三类各有独立风险清单 | 净资本/客户资金隔离、AUM及费率/自有投资、租赁信用与期限错配；不按一般制造业FCFF |
| 公用事业 | 股利DDM、现金流估值 | 管制回报、资本开支、债务、分红与现金匹配 |
| 房地产、控股、多元化 | 项目/分部NAV，普通股债权顺位桥接 | 回款、受限资金、到期债务、资产处置折价、分部重复计算 |

正式同行须同时满足：当前行业归属已核实、经济模型相同、主营可比有公告或人工确认依据、同一指标定义和报告期间可对齐。规模与经营模式差异逐项显示，不凭同板块就合格。初次最多准备20个候选公司的资料，按可比证据完整度、报告期间和规模接近度排序；缺少证据时按代码稳定排序，仅展示候选，不参与估值。补齐下一批需手动，不全市场自动抓取。

首版行业体系固定使用现有 `eastmoney-industry`，映射表带版本并保存取得的分类目录。验收遍历实际目录，逐个得到明确经济模型或 `unresolved`，不以模糊名称自动套通用估值；未解析也有通用研究清单和待识别主营提示。券商、资产管理、融资租赁分开清单；未支持的专有资产定价显示研究状态，不承诺全产业全方法数值覆盖。ETF/公募基金/REIT不混作普通A股企业估值。

正式样本少于5家时展示逐家公司但不发布分位结论；至少5家时显示排除自身的样本数、中位数、Q1/Q3及经验分位 `count(peer<=target)/N`，并列值同口径处理。亏损/非正PE不入PE样本；负净资产不入PB样本。不得简单平均各公司PE；不把相对低估称作绝对安全。历史自身分位使用最近5年可用估值日、披露实际起止和覆盖率，避免不同长度窗口比较。

## 估值引擎与显式假设

新增独立的确定性估值引擎，不复用现有短期预测的数值边界。金额用人民币元、股数用股、比率用小数。内部保留足够精度，最终每股显示2位；NaN/Infinity/布尔数值一律拒绝。输入须有来源或清楚标成 `user_assumption` / `model_proposal`。AI生成的是研究草案，不能自动把拟议假设变成已核实事实。

所有方法使用同一个 `ValuationCase`：方法、5年逐年输入、必要资本桥接、保守/基准/有利三组假设、敏感性、引用、适用性与缺口。保守值是有理由的一组不利假设计算结果，不是固定给基准打七折；三情景不自动赋概率。每组显式预测含增长所需投资/资本约束，不能只提高增长而不承担再投资。首版DCF/RIM只接受已核实的固定普通股资本基准；未来融资增发、回购或资本结构重组会使其不适用，直到完整资金与股数桥接得到核实。稀释压力测试可计算“不产生额外经营收益的普通股权益摊薄”影响，须标明这种假设，不冒充真实融资预测。DDM的逐年每股股息也必须交代股本及资本约束。

输入不是任意五年现金流数组。非金融经营模型必须给出 `R0,NWC0` 以及5年的营收增长、EBIT利润率、折旧/营收、capex/营收、经营NWC/营收、现金税率，逐年计算 `R_t=R_(t-1)*(1+growth_t)`、`EBIT=R_t*margin_t`、`FCFF=EBIT*(1-tax)+DA-capex-(NWC_t-NWC_(t-1))`。EBIT利润率含研发费用及折旧，资本化政策变更须单列，不能又减一次折旧。FCFE还须显式税后利息、净借款与归属普通股的调节。销量/价格有可靠基础时可改用量×价推营收；没有则营收增长就是明示预测，不能捏造销量。成本事件可改利润率但必须有成本金额/营收的桥接，不支持的事件驱动只保留定性。逐年增长和再投资输入均有假设ID；产品不接受AI绕过经营桥接直接填最终FCF。银行RIM输入普通股账面权益、5年ROE/分红/OCI及资本约束计划；DDM输入分红和其盈利/资本可持续依据；NAV输入不重叠资产/负债清单和调整。不能验证“增长投入足够”时标明未解决，暂停条件价位，不声称会计勾稽等于经济可行。

本次实现以下5个可审计计算器，按适用条件启用，不承诺每家公司5个都有结果：

1. **FCFE DCF**：`operating_equity=sum(FCFE_t/(1+ke)^t)+FCFE_terminal_year6/(ke-g)/(1+ke)^5`。输入是归属普通股的可分配权益现金流，不再减一次有息债务、不重复加股息。研究日已有非经营资产须明确 `included_in_flows`（释放及收益已进入预测）或 `separate`（完全排除在预测之外，单独加普通股净可归属价值）；两者互斥且必须对账，不允许一边都不计或两边都计。不能把全部现金未经经营需求扣除就加上。股本与稀释路径显式，不能把增发款加进FCFE又不增加股份。
2. **FCFF DCF**：同式以WACC折现FCFF得到经营企业价值，转普通股价值：`EV+经核实非经营可用资产−有息债务−其他优先索取权−少数权益`。只有明确排除在经营现金流外的资产可加入；不能把全部货币资金当多余现金。EV口径与少数权益扣减一致，缺桥接项不假设为0。终值第6年现金流必须由独立的稳定期利润率、税、折旧、投资和营运资本等输入重新算出；只有第5年已经处于该稳定状态时才等于 `FCF5*(1+g)`。缺稳定期投资/资本效率依据时不得用增长率直接放大最后一年FCF。
3. **剩余收益RIM**：`V0=B0+sum((E_t-ke*B_(t-1))/(1+ke)^t)`；5年后剩余收益按显式衰减系数 `omega∈[0,1]` 延续，续存值 `RI_5*omega/(1+ke-omega)` 于第5年折现。`B_t=B_(t-1)+E_t-D_t+净资本变动`；净资本变动、分红、回购与OCI需一致，无法建立普通股clean-surplus桥接时停用。支持期末股本路径后才给每股值，不把负净资产机械代入正常银行估值。
4. **股利DDM**：折现5年普通股现金股利及 `D5*(1+g)/(ke-g)`。需检验资本/偿债和分红可持续；回购不当作每个股东现金股息相加，而通过股份减少和未来每股分配体现。缺分红政策或增长与资本不相容时停用。
5. **调整NAV/SOTP**：已列明且不重叠的普通股可归属资产/分部价值减对应负债、税费、交易/处置成本及其他索取权，再除股数。资产折价/分部估值各有证据或显式假设；资产账面净值不能自动当可变现值；缺少重大分部/债务即不输出总值。

DCF/DDM必须 `discount>terminal_growth` 且两者差至少1个百分点，这是软件数值稳定政策而非经济定律；不满足时提示修改假设，不夹紧到合法值。所有方法逐项检查正股数、维度一致、预测年完整、证券/币种一致。非正普通股价值可显示为“不支持正价值”，不作为安全边际分母。

假设界面不预填一个可直接变成结论的“行业合理PE15倍”。折现率、长期增长、正常化利润率/量价、再投资、衰减、分配、稀释、NAV折价都列明。可显示明确标为教学/压力测试的示例，但示例不混进真实公司报告。模型可带引用提出假设，用户确认后生成 `confirmed` 版本；未确认版本保留草案数值、假设来源和敏感性，不显示可执行买入结论。确认不等于事实正确。

为避免泛用“利润×倍数”伪装内在价值，同业倍数只作交叉检查；没有合格绝对估值方法时，状态是 `research_only`。多个绝对方法不做任意权重平均：明确主方法选择及理由；若主方法与有效交叉方法的基准估值差超过30%（差额/主方法值），显示 `disputed`，暂停安全价位直到解释差异或修正输入。30%是需审查的产品阈值，不是统计置信度。

## 安全边际、陷阱与错误定价

价值参考用已确认主方法的保守普通股每股值 `V_low`。市场价 `P` 必须是同证券、同股本基准的不复权有效报价。

- `安全边际=(V_low-P)/V_low`；负数如实显示。
- `到保守价值的涨幅=(V_low-P)/P`，与上式分开。
- 用户要求的安全边际 `m∈[0,0.8]`，明确是偏好，不是模型发现；未设置时不生成“满足买入要求”结论。
- `满足该折价要求的参考上限=V_low*(1-m)`，称为条件参考价，不称必胜买点。
- 同时显示敏感性下更低的值、债务压力与资本稀释，不能只挑一个好看的数字。

规则给出 `research_only / draft / review_required / disputed / conditional / stale` 等状态，不输出“确定低估”。`conditional` 要求：数据可用、方法适用、假设已确认、当前报价可用、关键风险已处理、无未解决方法争议；其含义仅为“可按这些条件比较价格”。身份未核实、已核实重大风险、ST限制等沿用既有资格规则，暂停条件价位。未知审计意见/债务/受限现金等对所选方法构成关键缺口时同样暂停，不以未检索到代替无风险。

价值陷阱报告至少覆盖：利润现金含量、非经常损益、应收/存货、周期位置、维护与增长投入、短债与受限现金、持续经营/审计、治理及关联交易、少数股东与稀释、资本分配、产业衰退。不同产业用不同阈值，不给银行套制造业资产负债率红线。风险未知列为待核实并指明影响，不自动判断安全。

每条错误定价假说必须包含：市场担忧（若只是推断要标记）、支持证据、反证、影响哪个估值输入、验证节点、失效条件。用事实与可检验解释建立研究，不声称掌握市场所有参与者真实预期。没有可靠一致预期数据时，不能把同比增长叫“超预期”。

## 事件、历史案例与持有期

延用既有事件族、生命周期、原文与可比案例。新增 `ValueDriverChange` 仅允许改变有单位的经营/资本输入，例如销量、产品价格、成本、税率、capex、营运资本、折现率、分配和股本；附原值、新值、生效时间、持续/衰减、来源与反证。同一事件族同一输入只应用一次；与基准已纳入的变化不得再次叠加。没有可量化经营传导的数据则只写定性情景，不强制转成涨幅。

报告同时保留“无本事件变更的价值”和“应用后的价值”，差额是本假设下的价值变化，不等于未来股价涨幅。可比历史事件按已有市场/行业、预涨幅、估值、事件强度与成熟观察窗过滤，显示样本数/偏差；样本为0照实显示，不靠放宽未来数据弥补。行业当前成员不能冒充过去同行。事件股价反应只作价格是否提前反映的佐证，不直接把历史涨幅加到内在价值上。

6/12/24/36月的情景取每个终点之后剩余现金流/资产的价值，不把今天的V0乘增长率当届时市价。V0和Vh必须复用唯一的 `CashflowSchedule`：默认未来每12个月在估值日起周年末收付，日期缺日按该月最后一天；明确的分红实施日可替代默认日期，但必须同时重算V0和Vh。首版不自动把年末现金流改摊到月末。上述公式的整数t是简写，实际有日期的折现统一用 `(支付日-估值日).days/365.25`，终值的起算点和折现日期同属该排程；纯数学公式测试可直接使用1至5年的时间节点。DDM可直接重估终点剩余股息；FCF模型还必须有“自由现金流—实际分红—留存现金—未来非经营资产”的勾稽，不能把未分配FCF在终点价值中丢掉。首版若没有这套勾稽，只给当下DCF价值与持有期核查节点，不自动生成FCF终点回报；NAV无未来资产处置/负债计划时同理。价格兑现因子是显式假设，含“长期不纠偏”情景，不能自动令36月回归100%价值。终点总回报=`(终点股价+期间现金股息−买价−全部费用)/买价`；年化用同一365.25自然日年数，默认只显示未扣税费毛收益，填写税费/费用假设后才显示净收益。终点价格已除息且不含期间已分现金，禁止股息重复计算。回购仅走股本路径；固定股本方法遇到回购预期则停止该方法的终点数值。没有未来经营/分配/兑现假设时只显示价值与待验证条件，不画伪未来价曲线。

兑现因子严格定义为 `k_h=终点价格P_h/终点内在价值V_h`，故 `P_h=k_h*V_h`；不是随时间必然增大的纠偏比例。初始 `k0=P0/V0`；“长期不纠偏”指维持 `k_h=k0` 的初始折价率，不是维持原股价。另可比较 `k_h=1` 的充分纠偏假设，均非概率预测。每个终点/情景的k由显式假设给出，未填不自动补线性收敛。

压力测试至少重算：利润/FCF下行、资本开支增加、折现率上行、终值增长下降、稀释上升；银行使用ROE/信用成本/资本约束，NAV使用资产折价/处置延迟。每个冲击值和理由显式，不将机械压力值称为概率区间。显示终值占比、价值对各输入的敏感度、最易推翻论点的条件，以及现金/再投资/同业机会成本的用户基准。

## AI、费用与确认

复用现有模型网关和用量记录。新增一次可选的结构化价值研究调用，在同一次调用内明确区分经营质量、估值、反方、资本分配视角；这是同一模型的多视角复核，不能宣传独立专家投票。现有短期六角色保持原样；两者都选时最多新增一次价值调用，明确展示实际计费调用数和阶段。

AI仅返回带事实ID的解释、可证伪假说、候选输入与反证，不负责最终算术。只允许引用实际送入的证据，外部文字均当作资料而非指令；数值输入必须有字段/单位/期间/出处。代码检查身份、来源、可用时间、模型适用性、单位、数学约束、事件去重和资本桥接。未经确认的提议不能变为正式事实。用户可直接手动填写假设、不调用模型，计算本身免费。

“研究内容：短期交易 / 价值投资 / 两者”由用户主动选择，现有默认短期交易不变，避免暗增付费。页面只有统一的生成入口；价值区的“补齐资料/研究”将焦点与范围交给该入口。修改假设后的“确认假设并计算”是本地确定性重算，明确不调用AI。不会增加新的API Key或强制付费订阅。

## 版本、后台任务与接口

新schema版本 `value-research-v1`，通过现有追加式journal留存 `value_snapshot / value_assumptions / value_report / value_review`，与demo/live隔离。一个不可变 `ValueSnapshot` 绑定：code、cutoff、资料哈希、原始股本基准、来源配置代次、行业/同行证据、资格/风险、计算器版本；不依赖必须存在完整qfq历史。每个假设版本绑定snapshot，编辑采用 `expected_revision` 乐观并发控制。旧报告始终可查但不可冒充当前。

共享 `research_data` 持久任务，结果追加 `value_facts` 不替换旧字段；价值单独准备允许没有K线，不能被短期B/C模型缺失卡住。价值额外队列任务 `value_research` 复用MarketJobs执行器与profile发布保护，模型任务失败不自动重试付费调用：网络调用前先持久记录该任务已开始付费尝试，崩溃恢复后未知结果标记中断，不再发请求。UI重新连接/服务重启显示中断与手动重试。资料任务最多3次有界重试；同行子任务逐家公司释放执行权。角色进度按真实阶段：财报/同行/校验/AI解释/确定性计算/保存。显示耗时与剩余时间估计区间（无历史耗时则显示未知），完成与依据不足明确区分。

同一 `profile/code/snapshot/model/assumptions_revision` 的运行中价值任务原子复用，包括force请求。利用现有任务表 `(profile,key)` 唯一约束和事务内代次分配，不用随机nonce制造重复付费任务；force只在上一代终态后显式启动新代。持久付费尝试记录与任务代次绑定，重复POST/断线重发/跨进程竞争不能再消费一次模型。

接口沿用 `/api/v1/a-share/market` 身份边界：

- `GET /stocks/{code}/value-research`：仅读缓存/重算过时原因；无外部抓取、无模型。返回snapshot/report/assumptions/coverage/peer_status/stale_reasons/progress。
- `POST /stocks/{code}/value-data`：排队收集/复用本股资料及一批最多20个候选，body `{peer_offset:0, refresh:false}`，返回任务，不调用模型。每次最多一批，offset上限500。
- `POST /stocks/{code}/value-research`：body `{snapshot_id, force:false}`，显式付费生成草案；相同snapshot/model的完整缓存可复用，force才重新计费。无资料返回409并提供准备动作，不默默收费。
- `PUT /stocks/{code}/value-assumptions`：body `{snapshot_id,expected_revision,assumptions,confirmed}`，验证/留存版本。错误422、并发或过时409；不调用模型。
- `POST /stocks/{code}/value-evaluate`：body `{snapshot_id,assumptions_revision}`，确定性计算与保存；不调用模型。可在没有AI草案时独立完成。
- `POST /stocks/{code}/value-supplement`：body `{snapshot_id,facts:[...],attested:true}`，依上述手工补充契约生成新snapshot；条目上限50，URL限HTTP/HTTPS，引用每条最多2000字；来源冲突不自动确认。

输入模型 `extra=forbid`、有限数、最大长度与批量上限；错误返回字段级原因，不输出模型供应商异常原文/凭据。请求code与事实/假设code一致。队列发布时重新验证配置代次、profile、snapshot与假设revision，旧任务不能覆盖新状态。当前报价到下一交易日、资料/股本/行业/风险/假设版本改变后重新检查；财报latest_reconstructed不能用于历史回测。

## 验收与范围边界

- 样例数据测试稳定消费、周期资源、银行、亏损科技、资产型公司，验证不同方法与不可估值路径；真实联调选云铝股份与一家非资源A股，银行另做真实资料覆盖检查。真实数据不足必须交付缺口清单，不把它标为已估值。
- 检查累计/单季/TTM、元/万元/股、修订与可用日期、股本/少数权益/受限现金、负利润、利息分类、终值、分红/回购去重、同业不足、事件重复和历史穿越。
- 计算器测试有手算期望值；端到端必须证明“无AI也可计算”“有AI但假设未确认只能草案”“免费/付费切换不越权”“股票切换及版本过期不会串用”。
- 使用真实数据及一次明确触发的价值AI调用核对通路，不以模拟服务宣称联网跑通。已有用户授权实现和联调，所有花费只限本次该调用，失败不自动连环重试。
- 运行A股后端回归、受影响前端测试、前端构建和改动文件lint，解释已有无关lint问题。先备份，按文件白名单同步至本机运行目录，保存配置/数据/原报告，检查服务健康和页面。未获本次明确指令不提交/推送GitHub。
- 方法正确、数据完整都不能直接证明具有收益优势；验证以计算/契约正确和真实可用为界，未来有历史时点数据后再研究历史估值效果。
