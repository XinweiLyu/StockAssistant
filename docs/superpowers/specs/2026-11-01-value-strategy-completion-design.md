# 价值投资策略补齐设计

依据：用户已确认《现有价值投资策略审查与优化建议》（outputs/value-investing-strategy-audit-2026-11-01.md）并要求优化补齐；此前选择本会话直接实现。复用现有FastAPI/Python、React/TypeScript和数据源，保留现有七文件价格对照修复、全部交易/图表功能，不新增购买或训练依赖，不自动提交推送。

## 目标与验收
1. 修复终值一次性NWC永续化、所有股权方法库存股分母、V0/Vh日期不一致。数据未知不填0；既有DDM现金约束不放松。
2. 结构化经营研究：同期间同主体的财务质量、现金、资本回报/代理值、资本需求和来源。按经济模型适配，金融企业不套制造业ROIC。所有代理指标明确名称、公式与局限，缺关键项返回具体缺口。
3. 公司历史驱动底稿：收入/经营利润/现金/投资/周转等历史区间与年度路径，提出明确为待核对的公司专属假设，不能把历史区间当预测概率；区分原始事实、输入未送达、未来假设、方法不适用。
4. 同行补齐平均权益ROE、经营利润率和现金收益率，保持主体、日期、定义一致和主营证据要求；不足5家可显示个案，不发布分位。
5. 经济一致性检查：增长/再投资/ROIC、稳态一次性调整、终值依赖和债务/现金风险；方法适用性与关键现状分开。不以未来没有官方承诺一律拒绝草案，也不把未知现状填0。
6. 反向估值：在固定其他假设下，从价格求一个可识别参数或股利规模，披露基准、范围、其他固定参数及不可解；不得声称知道真实市场共识。不把缓存价格标为有效当前价。
7. 事件传导补齐DDM/RIM/NAV的适配字段，明确一次/暂时/结构/资本事件，按方法去重/期限/原值/来源校验；未来路径改变后重新估值，不直接叠加历史股价反应。无法桥接时保留定性及理由。
8. 持有复核：有来源的经营指标阈值与复核日期，记录假说/反证/失效，按新财务资料复核原假说。复用现有账户集中度与风险上下文，区分价值失效与短期波动，不自动交易。经营预测前瞻对照只比较已到期且口径匹配数据，禁止修订历史回测冒充当时可知验证。
9. 同页展示质量、驱动、同行、敏感性、预期与复核；价格对照输入和现有编辑功能保留。未知显示具体原因，自动草案/参考/正式核验状态清楚区分。
10. 真实本地数据及浏览器验收。允许按用户现有授权做一次实际模型联调，事前说明一次计费，不自动重试；如果仍partial如实记录具体缺口，禁止用规则试算伪装AI完成。测试结果不等于已证明盈利。

## 数学约定
DCF稳定期NWC分为持续增长所需资金和一次性比例重置：稳态NWC增量=第6年NWC*(g/(1+g))；一次性调整=总第6年增量-稳态增量，在第6年仅折现一次。g>-1。终值持久现金不包含一次性重置。
发行总股数仍与current_capital校验；所有股权方法另外显式区分库存与外部权益股数，有库存成本但缺数量时停止该每股路径。动态资本仍只支持DDM，未知库存数量不推算。
由快照cutoff绑定V0和Vh起点；明确case起点与cutoff不同则拒绝，payment_dates不能被忽略。保留ACT/365.25。
所有经济质量指标不合成为盈利概率；净利润主体、CFO主体不能混比；现金收益率明确为CFO-capex代理，不称严格FCFE。

## 边界
金融/保险/早期企业按专属方法与证据清单，不能保证每家公司都出数。缺真实市场预期及历史时点数据时保留未知。对已披露年报和最新季报采用各自口径与审计状态；不要求未来预测成为官方承诺。
