# 多板块同图资金趋势

用户澄清：希望同一张图比较多个板块今天资金流入的动态变化。此前单板块详情不足以满足这个需求；本次在已授权功能范围内纠正展示。

“行业与概念”页顶部新增全宽对比面板，位于原板块热图及成分股布局之前。每条曲线表示一个板块，共用9:30–15:00时间轴及0基线。默认关注6个板块、最多8个，可搜索勾选/移除；行业与概念独立选择，保留原热图/排行/成分股/个股K线。主力默认，也可切换超大/大/中/小单；金额（亿元）与净占比分别对比，不混叠单位。悬停/时间滑块联动表格显示同一采样桶的数值，最新观测单独列出，点击板块仍进入详情。

复用当前已验证的东财排行归一化及5分钟全分类共享采样，每次一次排行可覆盖所有板块；比较接口只读取所选板块观测并排队共享排行，不为每板块高频抓历史或调用模型。行业或概念分别记忆选择，默认值选定后固定，不随刷新换线。隐藏/离开停止轮询；切换分类/勾选会取消旧响应；本地偏好不能越过服务端代码类型校验。

横轴是今日系统观测时间，数据为累计净额，绝不将相邻累计值求和；午休/超过8分钟缺口断线，各类别不叠加。缺失留空，不把其他板块、其他日期或最近值前向填充到光标时间。当前公开快照缺乏源交易日期，因此标题明确“今日资金采样对比·源日期未核实”，不声称完整开盘以来分时曲线。只有服务实际采集到的点才画线，单点画点，未采集不造图。非交易日/开盘前明确暂停采样。免费排行当前连接失败必须直观提示，历史日净额不能顶替今天分钟线。
